# Aulea Viva | Calidad Académica Virtual

Sitio web oficial de **Aulea Viva**, consultoría especializada en calidad académica para educación virtual universitaria en Colombia.

🌐 **Sitio en vivo:** [auleaviva.com](https://auleaviva.com)

---

## 📋 Estructura del proyecto

```
auleaviva-web/
├── index.html          ← Página principal (estructura HTML)
├── script.js           ← Toda la lógica (3D, chatbot, animaciones)
├── CNAME               ← Conecta el dominio auleaviva.com con GitHub Pages
├── README.md           ← Este archivo
└── assets/
    └── favicon.svg     ← Icono de la pestaña del navegador
```

---

## ✏️ Cómo editar la página

### Cambiar textos
Abre `index.html` y busca el texto que quieras modificar. Está todo en español, fácil de identificar.

### Cambiar servicios
Los 6 servicios están en la sección `<!-- SERVICIOS -->` del archivo `index.html`. Cada uno tiene su título, descripción y características en formato `<article class="servicio-card">`.

### Cambiar respuestas del chatbot
Las respuestas del asistente virtual están en `script.js`, dentro del objeto `knowledge` (sección 8 del archivo). Modifica los textos y guarda los cambios.

### Cambiar el número de WhatsApp
Busca `573027465713` en ambos archivos y reemplázalo con el nuevo número (formato internacional, sin + ni espacios).

### Cambiar el correo
Busca `contacto@auleaviva.com` en ambos archivos y reemplaza.

---

## 🚀 Cómo desplegar cambios

1. Edita los archivos localmente
2. Sube los cambios a GitHub
3. GitHub Pages actualiza automáticamente en 1-2 minutos

---

## 🎨 Stack técnico

- HTML5 semántico
- CSS3 con variables personalizadas
- JavaScript vanilla (sin frameworks)
- Three.js (animación 3D del hero)
- Google Fonts: Antonio, Inter, JetBrains Mono
